# 问题3：可解释性情感预测建模与验证

## 1. 可解释性的形式化定义

题目要求解释必须"**可量化、可复核**"，包括三层：

| 层次 | 数学对象 | 含义 |
|---|---|---|
| 模态级 | $\boldsymbol{\phi}=(\phi_t,\phi_a,\phi_v)$，$\sum_m\phi_m=1$ | 各模态对本次预测的作用程度 |
| 主模态 | $m^\*=\arg\max_m\phi_m$ | 主要参考模态 |
| 片段级 | $w^m\in\mathbb{R}^K_{\ge0}$ | 模态 $m$ 内各时间步的重要性，$w^m_k$ 排序得 top-$r$ 关键片段 |

**总预测**：$\hat y=f(X)$，$f$ 为问题2 的共享骨干（三模态完整输入）。

---

## 2. 三个互补的解释来源（避免"只有注意力=伪解释"的硬伤）

> 仅用注意力权重作解释在顶会上已被反复质疑（注意力不等于重要性）。本方案用**三源交叉验证**：博弈论（Shapley，有公理化保证）+ 梯度（IG/Grad-CAM，细粒度）+ 遮挡（Occlusion，模型无关的黄金标准）。三者一致时解释可信度最高，不一致时作为错误归因线索。

### 2.1 模态级：精确 Shapley 值（**模态只有 3 个，8 个子集，可精确计算**）

定义效用函数 $v(S)$ 为只使用模态子集 $S\subseteq\{t,a,v\}$ 时模型在验证集上的表现（如 $-\mathrm{MAE}$）或本样本的带符号预测值：
$$v(S)=\mathrm{perf}\big(f(\{X^m\}_{m\in S})\big)$$

模态 $m$ 的 Shapley 值（精确枚举 $2^3-1=7$ 个非空子集）：
$$\phi_m=\sum_{S\subseteq \mathcal{M}\setminus\{m\}}\frac{|S|!\,(3-|S|-1)!}{3!}\big[v(S\cup\{m\})-v(S)\big]$$

**归一化作用程度**：$\pi_m=\dfrac{\mathrm{ReLU}(\phi_m)}{\sum_{m'}\mathrm{ReLU}(\phi_{m'})+\epsilon}$，另报告原始 $\phi_m$（带符号，正=促进、负=抑制）。

**两套口径都报告**：
- **样本级**（per-sample）：$v(S)$ 取该样本自身预测值 → 得到每条样本的 $\pi_m$，写入附件4 解释 CSV。
- **数据集级**（global）：$v(S)$ 取验证集 $\Delta$MAE/F1 → 得到全局模态重要性排序，用于论文结论。

### 2.2 片段级：时间重要性 $w^m_k$

**(a) 注意力 + 梯度（细粒度、单次前向）**
Grad-CAM 式：$w^m_k=\mathrm{ReLU}\Big(\sum_c \bar\alpha^c_m A^{m,c}_k\Big)$，其中 $A^{m,c}_k$ 为模态 $m$ 第 $c$ 个注意力头在时间步 $k$ 的权重，$\bar\alpha^c_m$ 为对应头的梯度全局均值。

**(b) 积分梯度（IG，公理化）**
$$IG^m_k=(X^m_k-X'^m_k)\int_{\alpha=0}^{1}\frac{\partial f\big(X'+\alpha(X-X')\big)}{\partial X^m_k}\,d\alpha\ \approx\ \frac{1}{L}\sum_{l=1}^{L}\frac{\partial f}{\partial X^m_k}\Big|_{X'+\frac{l}{L}(X-X')}$$
基线 $X'$ 取**该模态在训练集中的均值特征**（比零基线更符合语义）。时间步重要性 $w^m_k=\|IG^m_k\|_2$，词/维度级重要性由 $IG^m_{k,\cdot}$ 的分量给出（可直接映射到文本词）。

**(c) 遮挡（Occlusion，模型无关的验证基准）**
$$w^m_k\ \propto\ \big|\,\hat y(X)-\hat y(X\ \text{去掉段}k\,\text{后的模态}m\,\text{特征})\,|\quad\text{或取多次随机遮挡的期望}$$
首/末段用相邻段填充（保持长度），避免引入长度伪影。

**融合**：$w^m_k=\mathrm{norm}\big(\gamma_1 \tilde w^{\text{att}}_k+\gamma_2 \tilde w^{\text{IG}}_k+\gamma_3 \tilde w^{\text{occ}}_k\big)$，$\gamma$ 取等权或按与遮挡的一致性在 valid 上标定。

### 2.3 证据定位（对应文献[8]）

| 模态 | 映射规则 | 输出字段 |
|---|---|---|
| 文本 | 取 $w^t_k$ 最高的段，回溯该段内 $IG$ 分值最高的词，合并为**连续词片段**并给字符级高亮 | `text_evidence`, `text_char_spans` |
| 语音 | 把高 $w^a_k$ 的段合并为**连续时间区间**，对齐到原始波形 | `audio_start_s`, `audio_end_s` |
| 视觉 | 高 $w^v_k$ 段内取**该段视觉活跃度（AU 强度总量）最大的帧**作为关键帧 | `vision_frame_idx`, `vision_time_s` |

**关键帧回看**：附件4 提供原始视频，因此可导出 `keyframes/{id}_t{k}.jpg` 拼图，在论文中直接展示"模型看的是哪一帧"，这是最有说服力的证据。

## 3. 解释质量的量化评价（题目"可量化、可复核"的落地）

| 指标 | 定义 | 期望 |
|---|---|---|
| **忠实性 Comprehensiveness** | 删除 top-$r$ 重要片段后预测的变化量（相对全模态） | 越大越好 |
| **充分性 Sufficiency** | 只保留 top-$r$ 片段作为输入时的预测保真度 | 越接近全模态越好 |
| **Deletion / Insertion AUC** | 按 $w$ 从高到低（或低到高）逐段删除/插入，绘制预测值曲线并积分 | Deletion AUC 越低越好 |
| **模态解释忠实性** | $\pi_m$ 与真实"删掉该模态造成的退化"的 Spearman 相关 | 越高越好（>0.6 视为可信） |
| **稳定性** | 对输入加小扰动 $\delta$（噪声/时间抖动）后解释的一致性 $\max_i\|e(x)-e(x+\delta_i)\|_1$ | 越小越好 |
| **稀疏性** | top-$r$ 片段的 $w$ 质量占比（$r=5$ 时） | 越高越易读 |

**必做的"复核实验"**：随机选 30 条验证样本，比较人工判读的高亮片段与真值强度变化的对应关系（例如高亮词是否含情感词），报告命中率。这比单纯堆指标更能说服评委。

## 4. 模型与训练

**骨干**：直接复用问题2 的 MRF-Net（去掉缺失分支，修正则改为三模态完整输入）。**同一模型解决两问**，论文中说明"鲁棒性与可解释性共享表示，解释结果可反向指导鲁棒性分析"。

**解释性正则（让解释更稳定、更稀疏）**：
$$\mathcal{L}_{xai}=\alpha_1\underbrace{\|w\|_1}_{\text{稀疏}}+\alpha_2\underbrace{\mathrm{TV}(w)}_{\text{时间平滑}}+\alpha_3\underbrace{\big(\pi_m-\pi_m^{\text{occ}}\big)^2}_{\text{与遮挡一致性}}$$
建议 $\alpha_1=10^{-3},\alpha_2=10^{-3},\alpha_3=0.1$，在 valid 上按"忠实性 - 性能"加权目标选择。

**训练方案**：与问题2 相同（AdamW、cosine、早停、5 种子）。**分类阈值同样在 valid 上选**。

## 6. 分析与对比实验

1. **三模态作用差异对比**：全样本 $\pi_m$ 的箱线图/小提琴图；按真值极性分层（正/中/负样本的 $\pi_m$ 分布是否不同）；按强度 $|y|$ 分层的 $\pi_m$ 趋势（猜测：$|y|$ 越大 → 文本/语音作用越突出）。
2. **与"模态删除"实验的一致性**：把问题2 的缺失实验结果与问题3 的 $\phi_m$ 排序对照，二者一致则相互印证（论文亮点：**可解释性结论被鲁棒性实验独立验证**）。
3. **局部片段重要性分布可视化**：取 20 条样本堆叠成 (20×50) 热力图并按真值排序，观察"情感峰值段"是否稳定高亮。
4. **错误归因**：解释结果与错误样本的关联分析——例如中性样本 $\pi_m$ 是否趋于均匀（模型无明确依据 → 易错）；比较错误样本与正确样本的忠实性指标。
5. **消融**：去掉 $\mathcal{L}_{xai}$、去掉 IG 项只留注意力、$\gamma$ 权重不同组合对忠实性指标的影响。
