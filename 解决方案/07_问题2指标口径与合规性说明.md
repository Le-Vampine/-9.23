## 3. 指标口径的具体决定

| 项 | 决定 | 理由 |
|---|---|---|
| 主报集合 | **valid** | 赛题第 (4) 项明确要求；且附件3/4 无标签 |
| 极性主指标 | **Macro-F1 + Accuracy** 并列 | 题目只写"F1 值"；类别不平衡（约 28%/22%/50%），Macro-F1 能暴露中性类的失效 |
| 每类 F1 | 一并报告（neg/neu/pos） | 中性类 F1 目前最低（约 0.40），是论文需要解释的薄弱点 |
| 决策阈值 θ | **单一对称阈值**：$s<-\theta$ 负、$|s|\le\theta$ 中、$s>\theta$ 正 | 与题目"0 仅属中性"的标签定义一致；且题目只允许选"决策阈值"（单数概念） |
| θ 选择准则 | 在 valid 上**最大化 Macro-F1**，同时给出 ACC 最优 θ 与折中 θ 作敏感性分析 | 只用 valid 选择；曲线展示稳健区间 |
| 分类头口径 | **主口径**（`acc_head` / `f1_head`，即 `acc`/`f1`） | 直接由附件2 `classification_labels` 监督，与训练目标一致；不受强度分数尺度（收缩/校准）影响。θ 阈值口径作**对照** |
| 强度主指标 | **MAE** 为主，Pearson 为辅，CCC 作参考 | MAE 是主损失与主判据；CCC 题目未要求，仅作稳健性说明 |
| 统计报告 | 多种子给 mean±std；单次比较给 bootstrap 95% CI 与 McNemar 检验 | n=728/727 时 ACC 标准误 ≈1.8%，<2% 的提升必须检验 |

> ⚠️ **历史勘误**：本表早期一行曾写“分类头只作对照、与 θ 口径不同源”，
> 与后来固化的**主口径=分类头**（见 `report_p0.md`、`metrics_*.json` 的 `primary` 字段）相矛盾，已修正。

### 3.1 Acc-2 报法（2026-09-24 固化）

文献（CMU-MOSEI 系）主报 **Acc-2** 两种设置：Acc-2(负/正) 只在 $|y|>0$ 上判正负；Acc-2(负/非负) 判 $y<0$。
我们此前只报了"三分类 ACC"，与文献**不可直接比较**；且此前用"回归分数 θ=0 阈值化"得到 Acc-2，**系统性偏低**。

**实测（B = 42+43 集成，附件2 test n=727）**：

| Acc-2 实现路径 | 负/正 | 负/非负 |
|---|---|---|
| 平凡多数类基线 | 0.6362 | 0.7153 |
| 回归分数 θ=0 | 0.8489 | 0.8074 |
| 回归分数 + valid 选优 θ（−0.26） | 0.8489 | 0.8281 |
| **分类头概率构造**（$p_{\text{neg}}$ vs $p_{\text{neu}}+p_{\text{pos}}$）| — | **0.8514** |

**决定**：
1. **Acc-2 主报"分类头概率构造"口径**——免阈值调参、三个模型上一致优于回归口径（B 0.8514 / E1 0.8349 / q2v3 0.8294），且不易过拟合；
2. 回归分数口径（θ=0 与 valid 选优 θ）**并列作对照**；
3. 全部写入 `code/02_model/perclass_report.py::acc2_views()`，每次评估自动产出，避免口径漂移；
4. **对照锚点**：文献 MOSEI **clean 全模态** Acc-2 ≈ 84–86%，**random-missing 协议** ≈ 71–79%；
   我们 0.849/0.851 落在 clean 区间下沿，**不属于"中下"**——此前"0.78–0.81"的说法源于用 valid + 回归口径对标文献 test + 分类头口径，属口径错位。
### 3.2 缺失率口径（2026-09-24 固化，规范定义 **D1**）

论文与提交物中「缺失率 $\rho$」全部采用下列定义，**不得混用**：

| 项 | 决定 |
|---|---|
| 缺失判定 | **连续 ≥2 帧全零**（题目原文「部分**连续**时间段不可用」）|
| 统计区间 | `[0, 末个非零帧]`。附件3/4 无 `*_lengths` 字段，末个非零帧之后只能是**尾部填充**故排除；**首部零帧属于「开头一段不可用」，计入缺失** |
| 缺失率 | $\rho$ = 缺失帧数 / 统计区间长度 |
| 整模态缺失 | 整条全零的样本记 $\rho=1.0$（附件4 视觉 1/20）|
| 位置 | 缺失段**中心**在统计区间上的归一化坐标 $p$ 分箱：头 $p<1/3$、中 $1/3\sim2/3$、尾 $>2/3$ |

**实测结果（附件3，n=30）**

| 模态 | 含缺失样本 | 整模态 | ρ mean | p50 | p90 | max | 位置（头/中/尾）|
|---|---|---|---|---|---|---|---|
| text | 0/30 | 0 | 0.000 | 0.000 | 0.000 | 0.000 | — |
| audio | **17/30（56.7%）** | 0 | **0.101** | 0.097 | 0.224 | 0.400 | 0.46 / 0.27 / 0.27 |
| vision | **18/30（60.0%）** | 0 | **0.107** | 0.118 | 0.224 | 0.400 | 0.43 / 0.29 / 0.29 |

**为何选 D1（另两种口径不采用）**

| 口径 | 差异 | 为何不采用 |
|---|---|---|
| D2：头尾都裁 | audio 14/30、vision 15/30；ρ mean 0.080 / 0.086 | 把仅在**开头**缺失的样本判为「无缺失」（audio/vision 各少 3 条），与题目「部分连续时间段不可用」不符 |
| D3：分母用固定总长 50 | 计数与 D1 相同，但 ρ mean 被稀释为 0.043 / 0.047 | 50 含**尾部填充**，分母不是「可用时长」，会把缺失率人为缩小约一半 |

**2026-09-24 修正的两处错误**
1. `infer_att3.py` 原用 `M[..., i].mean(1)`（**除以固定总长 50**），即 D3 → 已改为 `缺失帧数 / (~pad).sum()`，
   并对整条全零样本置 $\rho=1.0$ 且 `missing_regions` 记 `[[0, L]]`；
   修正后 `pred_att3.csv` 的 `missing_audio_ratio` 均值 0.0433 → **0.1011**（与规范表逐位一致），预测类列**完全未变**。
2. 中途曾一度把规范表改为 D2（并据此得出「audio 46.7% / mean 0.080」）——**该修正是错的**（丢弃了首部缺失），
   已回退为 D1。证据：旧表的 `frac_with_missing / mean / p90 / max` = 0.5667 / 0.101 / 0.224 / 0.400
   与 D1 **逐位吻合**，说明旧值口径本就正确；旧表**唯一**的真实问题是 `head/middle/tail` 三列由 config 先验硬编码

## 4. "在验证集上做校准"是什么，为什么合规

**定义**：模型原始回归分数 $\mu$ 存在系统收缩（实测：负类平均预测高于真值 +0.61，正类低 −0.54）。
校准是在**验证集**上拟合一个后处理映射，把 $\mu$ 变换为 $\hat s$：

$$ \hat s = a\,\mu + b,\qquad (a,b)=\arg\min_{a,b}\ \frac{1}{N_v}\sum_{i\in\text{valid}}\bigl|a\,\mu_i+b-y_i\bigr| $$

**合规依据**：

1. 赛题规定"模型结构、超参数与决策阈值在**验证集**上选择"——校准系数本质是后处理超参，属于该授权范围；
2. 赛题允许对附件2 训练集/验证集做标准化等基础预处理；
3. 校准**不使用**附件2 test 与附件3/4 的任何标签；
4. 校准后**重新在 valid 上选 θ**，与赛题规定一致。

**必须配套的动作（防止乐观偏差）**：

- 在附件2 test 划分上核验校准是否泛化（test 上的 MAE 也下降才算真实收益）；
- 在论文中写明"校准系数在验证集上拟合，测试集仅用于最终评估一次"；
- 报告 bootstrap 置信区间；对比不同方案用 McNemar 检验；
- 不在 test 上反复挑选版本。

**校准的边界**：不得使用外部数据集、不得使用附件3/4 的任何信息（含其分布）来拟合系数。

## 5. 非对称阈值 / 类先验校正的合规性边界

非对称双阈值（$\theta_{neg}\ne\theta_{pos}$）或分数平移 $s'=s-b_c$ 会**改变中性判定的边界**，
与题目"0（且仅 0）属于中性"的定义存在偏差。因此：

- **不作为提交 CSV 的主口径**（提交标签仍由单一对称 θ 生成）；
- 仅作为"探索性改进"在消融或讨论小节报告，并同时给出与题目定义一致的对照结果；
- 若采用，必须在论文中给出阈值选择的论证（如类先验偏移校正的原理）。

## 7. 需在论文中如实声明的局限

1. **附件3 的文本缺失不可观测**（30 条样本的有效区间内无全零列）→ 文本模态始终按完整处理，
   靠训练期强制模拟文本缺失兜底；附件3 上的文本鲁棒性无法直接验证。
2. **附件2 无 `audio_lengths` / `vision_lengths` / `annotations` 字段**（与题目表2 描述不符）
   → 有效长度由"尾部连续全零"推断；**填充(pad) 与真实缺失(miss) 严格分离**。
3. **valid 与 test 的标签强度分布不同**（test 中 |y|>1.5 占 22.6%，valid 占 17.9%）
   → 两划分的 MAE 落差需先做分布校正再解释（见 `report_p0.md` 第 6 节）。
4. **valid 被多次使用**（早停、θ、校准）→ valid 指标存在轻微乐观偏差，最终结论以 test 核验为准。

### 8.3 阈值与后处理结论

| 项 | 结果 |
|---|---|
| θ 选择 | θ=0.30 同时是 Macro-F1 最优与 ACC 最优（三准则一致）→ 选择稳健 |
| 双头融合 | valid 上最优 α=0 → 回归头已含分类头信息，**无增益**，不采用 |
| 非对称阈值 | valid 最优退化为对称（θ_neg=θ_pos=0.30）→ **不采用**，避免偏离题目中性定义 |
| 仿射校准（OLS） | $a=0.9503,\ b=+0.1002$，校准后重选 θ=0.32 |
| 校准效果 | valid MAE 0.5873→**0.5826**；test MAE 0.6521→**0.6485**；test ACC 0.6149→**0.6341**；test Macro-F1 0.5918→**0.6091**；**但 valid ACC 0.6195→0.6113（略降）** |
| 采用决策 | 按赛题"在验证集上选择"的规则，**主口径不校准**（valid 分类指标更优），校准列为可选改进与敏感性分析 |
| 显著性 | McNemar：θ 口径 vs 分类头口径 p=0.054（临界）；基线 vs 校准 p=0.302（不显著） |
| 分布校正 | valid 分桶 MAE 按 test 标签分布加权 = 0.6240（实际 test 0.6521）→ 落差中约 **0.028** 由标签强度分布差异解释 |
