## 0. 一句话方案

**不新建模型**：以问题2 的 MRF-Net 两种子集成（`runs/ens_top2`）为唯一骨干，在其上做**三源交叉解释**
（精确 Shapley + 积分梯度 + 遮挡），输出「模态作用度 $\pi_m$、时间重要性 $w^m_k$、证据定位」三类可量化结果；
在**附件4** 上给出预测 + 解释 CSV 与解释卡，在**验证集**上给出解释质量指标与错误归因。

理由（§2 展开）：
1. 题目要求"同一模型既给预测又给解释"，且问题2 与问题3 共享骨干能让"可解释性结论被鲁棒性实验独立验证"——这是本方案最有力的一条论文逻辑，重训新模型会削弱它；
2. 骨干已在 CPU 上训好且指标与论文一致，问题3 的全部算力需求实测仅约 6 分钟（§1.2），**时间应花在解释的口径与验证上，而不是重新训练**；
3. 注意力权重单独当解释在方法学上站不住（注意力≠重要性），必须用博弈论（Shapley）+ 梯度（IG）+ 遮挡（模型无关）三源互证。

### 1.3 ⚠️ 必须优先决策：发现一个既存的口径缺陷（影响问题2 已提交文件）

**证据链（全部实测，可复核）**

1. 附件2 的 `text` 尾部填充行**非零**（BERT 对 `[PAD]` 的隐状态），唯一可靠的长度来源是 `text_bert` 的注意力掩码；
   实测附件2 valid 文本有效长度均值 25.6/50，仅 6.5% 的样本尾部全零。
2. `data_att/att3_aligned.pkl`、`att4_aligned.pkl` 由 `encode_att_text.py` 生成时**未写入 `text_bert`/`*_lengths`**，
   于是 `build_split` 退化为"尾部全零推断"→ 文本 pad 全为 False，即**文本 50 步全部当作有效内容**（真值只有 13–50 步）。
3. 该口径的代价（在附件2 验证集上做同模型对照实验）：
   文本按正确长度掩码 → **MAE 0.5866、ACC 0.6223**；把文本 pad 强制为"全 50 有效" → **MAE 0.8514、ACC 0.3310**，
   68.5% 的样本分类标签改变。
4. 现有提交文件正是"全 50"口径的产物：用缓存 pkl 重跑推理，与 `submission/pred_att3.csv`、`pred_att4.csv`
   的分类标签一致率均为 **1.000**（反证成立）。
5. 用原始 附件3/4 pkl 的 `text_bert` 掩码修正文本长度后（附件3 的字段在 `test` 子字典内）：

| 数据集 | 修正后文本有效长度 | 标签改动 | 平均强度变化 | 极性分布变化 |

| 附件3（30 条） | 8 / 22.2 / 50（原 50） | **7/30** | +0.3106 → **+0.2451** | 6/11/13 → **6/14/10** |

## 2. 问题3 的数学建模（实施级定义）

### 2.1 记号与总目标

设骨干 $f$ 把三模态输入 $X=(X^t,X^a,X^v)$ 映为 $(\hat y,\hat p)\in\mathbb{R}\times\Delta^2$，本方案对 $f$ 不做任何改动。解释输出三层：

$$\underbrace{\pi=(\pi_t,\pi_a,\pi_v)}_{\text{模态作用度}},\qquad
\underbrace{m^\*=\arg\max_m\pi_m}_{\text{主要参考模态}},\qquad
\underbrace{w^m\in\mathbb{R}^K_{\ge0}}_{\text{模态 }m\text{ 的时间重要性}}$$

### 2.2 模态级：精确 Shapley（8 个子集全枚举）

$$\varphi_m=\sum_{S\subseteq\mathcal{M}\setminus\{m\}}\frac{|S|!\,(3-|S|-1)!}{3!}\big[v(S\cup\{m\})-v(S)\big],\qquad \mathcal{M}=\{t,a,v\}$$

- **屏蔽语义**：把模态 $m$ 的全部有效位置置 `miss=1`（而不是"特征置零但 `miss=0`"）。
  理由：模型训练时见过"整模态缺失"（`mod_dropout=0.15`），`miss=1` 才是它在语义上理解的"这个模态没有"；
  另做 `pad=1`（完全不可见）的敏感性对照，报告两种语义下 $\varphi$ 的 Spearman。
- **两套效用函数**（都算，主口径在 valid 上定）：
  - $v_\mu(S)$：集成平均强度预测（有符号）→ 解释**强度判断**的依据；
  - $v_p(S)$：预测类别的概率 → 解释**极性判断**的依据。
- **两个层级**：
  - 样本级：每条样本一个 $(\varphi_t,\varphi_a,\varphi_v)$ → 写入附件4 解释 CSV；
  - 数据集级：$v(S)=-\mathrm{MAE}(S)$ 或 Macro-F1（在 valid 上）→ 全局模态重要性排序，用于论文结论。
- **归一化两方案**（valid 上择优，另一作对照）：
  $\pi_m=\dfrac{\mathrm{ReLU}(\varphi_m)}{\sum_{m'}\mathrm{ReLU}(\varphi_{m'})+\epsilon}$ 或 $\pi_m=\mathrm{softmax}(|\varphi_m|/\tau)$。
  ⚠️ 实测样本 01 的三个 $\varphi$ **全为负**（$\varnothing$ 子集的基线预测 0.2015 就已经很"高"，加模态反而降低）→
  ReLU 口径在该样本上会退化为全零，故**必须有 softmax 口径作备份**，并用"与真实删模态退化 ΔMAE 的 Spearman"在 valid 上选主口径。

### 2.3 片段级：时间重要性 $w^m_k$（三源）

| 源 | 定义 | 特点 | 实测可行性 |
|---|---|---|---|
| (a) 注意力梯度 | $w^{att}_k=\mathrm{ReLU}\big(\sum_c \bar\alpha^c\,A^{c}_k\big)$，$A$ 取 `alpha` 中该模态的 50 个 token | 单次前向、快 | ✅ `alpha` 可得 |
| (b) 积分梯度 | $w^{ig}_k=\big\lVert (X^m_k-X'^m_k)\odot\frac{1}{L}\sum_{l}\nabla_{X^m_k}f\big(X'+\frac{l}{L}(X-X')\big)\big\rVert_2$，基线 $X'=$ 训练集均值（归一化空间即 0） | 有公理化保证、可下钻到词 | ✅ 梯度可用 |
| (c) 遮挡 | 用相邻段替换长度 $w=3$ 的窗口（首/末段用邻段填充以保长度），$w^{occ}_k=\lvert \hat y(X)-\hat y(X_{\setminus k})\rvert$ | **模型无关**，作为验证基准 | ✅ 算力足够 |

融合：$\tilde w=\mathrm{norm}(w)$ 后 $w^m=\mathrm{norm}\big(\gamma_1\tilde w^{att}+\gamma_2\tilde w^{ig}+\gamma_3\tilde w^{occ}\big)$；
$\gamma$ 在 valid 上按"与遮挡源的 Spearman 最大"标定，并报告等权对照。

### 2.4 证据定位（对应题目"可对应至原始文本片段、语音时段或视觉关键帧"）

| 模态 | 映射规则 | 输出字段 |
|---|---|---|
| 文本 | 取 $w^t_k$ 最高的段 $k$，其**词号即 $k$**（对齐粒度已验证，§1.2）；再用 `text_bert` 的 token 序列 + `vocab.txt` 解码出词，合并 `##` 续接，用 `difflib` 对齐回原始 `raw_text` 得到**字符区间** | `text_evidence`、`text_char_span`、`text_seg` |
| 语音 | 高分段的段号 → 时长区间：$t_k\approx\frac{k+0.5}{L_a}\cdot T_{video}$（比例映射；附件2 不提供逐词时间戳，须在论文中声明为近似），再用视频音频轨的能量曲线佐证 | `audio_start_s`、`audio_end_s`、`audio_seg` |
| 视觉 | 高分段内取视觉活跃度（AU 强度总量）最大的帧序号，映射到视频帧时刻并抽帧 | `vision_frame_idx`、`vision_time_s`、`keyframe_{id}.jpg` |

**依赖说明**：词表 `bert-base-uncased/vocab.txt`（226 KB，实测 hf-mirror 可取，**行号即 token id**，无需安装 `transformers`）；
视频抽帧/音频提取用 `imageio-ffmpeg`（自带 ffmpeg.exe，`uv` 实测可装 `imageio-ffmpeg==0.6.0`）；
视频时长用纯 Python 解析 mp4 `mvhd`（已验证，无需额外依赖）。

### 2.5 解释质量的量化指标（题目"可量化、可复核"）

| 指标 | 定义 | 期望 |
|---|---|---|
| 忠实性 Comprehensiveness | 删除 top-$r$ 片段后 $|\hat y$ 变化$\rvert$（$r=5$） | 越大越好 |
| 充分性 Sufficiency | 只保留 top-$r$ 片段时的预测保真度 | 越接近全模态越好 |
| 删除/插入 AUC | 按 $w$ 逐段删除（或插入）绘制预测曲线并积分 | 删除 AUC 越低越好 |
| 模态忠实性 | $\pi_m$ 与"真删该模态的 ΔMAE"的 Spearman | >0.6 视为可信 |
| 稳定性 | 加 $\pm$ 小扰动（$\sigma=0.05$ 噪声、时间抖动 1 步）后解释的 $L_1$ 变化 | 越小越好 |
| 稀疏性 | top-5 片段的 $w$ 质量占比 | 越高越易读 |

## 6. 论文写作方案（替换 §5.3 占位）

**新 §5.3 结构（与题目四条要求一一对应）**

1. **可解释性的形式化定义**：三层解释（模态级/主模态/片段级）+ 与题目"可量化、可复核"的对应关系；
2. **三源解释与融合**：Shapley 公式（含 3 模态可精确枚举的论证）、IG 公式与基线选择、遮挡定义、融合与 $\gamma$ 标定；
3. **证据定位规则**：文本词/字符 span、语音时段、视觉关键帧；**声明**段号↔词号的对齐依据（$r=1.000$ 实测）与时间比例映射的近似性；
4. **解释质量指标与验证**：2.5 节六项指标 + 人工复核（抽 30 条 valid 判读高亮片段是否含情感线索，报命中率）；
5. **典型样本解释卡**：3–5 张（正/中/负），每张配"模型依据"文字；
6. **三模态作用差异**：箱线图 + 分层分析 + 与问题2 缺失实验的互相印证（**本节是全文亮点：可解释性结论被鲁棒性实验独立验证**）；
7. **附件四全量结果**：预测分布表 + 图 + 解释结果汇总；
8. **验证集错误归因**：解释维度归因（中性样本解释熵更高 → 说明"模型无明确依据 → 易错"）。

**新增参考文献（§5.3 必须引用）**：Shapley（Lundberg & Lee, NIPS 2017）、积分梯度（Sundararajan et al., ICML 2017）、遮挡（Zeiler & Fergus, ECCV 2014）、注意力≠解释的批判（Jain & Wallace, NAACL 2019）；CMU-MOSEI 原论文（已在文献表 ref1）可用于"可解释动态融合图"的对照。

**排版约束（沿用 skill 与本文档约定）**：图表命名 `Q3_{内容}_{图表类型}.png`；每张图表说明 **100–150 字**；单页图表占比 ≤2/3、禁止图挨图；正文页数 21–30 页；交付前用 `05_paper/tools_audit_captions.py` 与 skill 的 `scripts/check_layout.py` 复核；XeLaTeX 编译无乱码。
