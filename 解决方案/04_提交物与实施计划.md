## 2. 附件体积控制（≤50 MB 是硬要求）

| 内容 | 原始估计 | 压缩策略 |
|---|---|---|
| 问题1 100 条特征 | 100×50×(768+74+35)×4B ≈ **17.5 MB** | **float16** → 8.8 MB；`.npz` 再压 → 约 4–8 MB |
| 模型参数 | 3 个模型 × <5 M 参数 ≈ 60 MB | 只存 `state_dict` + `float16`，或只存最佳 1 个 |
| 关键帧图片 | 易爆 | 每样本 1 张、JPEG q=70、最长边 320 px；或拼成长图 |
| 代码/日志 | 小 | 日志只留摘要 |

**总控建议**：`features .npz`（8 MB）+ 1 个 checkpoint（5 MB）+ 关键帧（10 MB）+ 代码（1 MB）+ CSV（<1 MB）≈ 25 MB，安全。

## 3. 实施计划（按 4 天赛程排）

| 时段 | 任务 | 产出 |
|---|---|---|
| D1 上午 | 元数据核查、附件2 结构探查（含"500 步是否截断"验证）、环境搭建、基线跑通（MMSA 工具箱） | 数据核查报告、基线指标 |
| D1 下午–D2 上午 | 问题1 全流程：解复用 → 三模态提取 → 对齐 → 校验 → 汇总表 + 典型样本图 | `features_100.pkl`、`feature_summary.csv`、对齐图 |
| D2 下午 | 缺失模拟引擎 + MRF-Net 最小版（mask 感知 + 重建）跑通；三因素实验脚手架 | 首版结果、实验矩阵脚本 |
| D3 | 加分解/代理/专家/蒸馏；全因子缺失实验（5 种子）；消融；附件3 推理出 CSV | 规律分析图表、消融表、`pred_att3.csv` |
| D4 上午 | 问题3：Shapley + IG + 遮挡；解释卡；忠实性指标；附件4 推理出 CSV | `pred_explain_att4.csv`、解释卡图 |
| D4 下午 | 论文撰写、图表美化、附件打包、匿名性自查、复现说明 | 论文终稿 + 附件包 |

> 若时间紧张，**优先级**：问题1 全覆盖 → 问题2 的 mask 感知 + 重建 + 蒸馏（三项增益最大） → 问题3 的 Shapley + 遮挡（最少代码、最强说服力）。分解/代理/专家/不确定性可降级为"可选消融"。

**创新点提炼（摘要与结论各写一遍）**
1. 提出统一"特征契约"，使问题1 自生成特征与附件2 同构，实现三问同一输入接口（方法学一致性）。
2. 掩码感知 + 跨模态重建 + 代理令牌 + 动态专家的**四重互补缺失处理**，并以**教师-学生蒸馏**（含关系蒸馏与动态权重）提供最强鲁棒性增益。

4. 用**方差分析 + 退化曲线拟合**把"缺失影响规律"从定性描述提升为统计推断。

## 5. 风险与对策

| 风险 | 影响 | 对策 |
|---|---|---|
| COVAREP/OpenFace 安装困难（MATLAB、许可） | 问题1 阻塞 | 回退：openSMILE eGeMAPS(88d) + 线性投影到 74 维；MediaPipe 关键点统计量投影到 35 维；论文如实说明并给"同构性论证" |
| 自生成特征与附件2 相似度低 | 问题1 可核验性受质疑 | 强调"维度一致 + 时间网格一致 + 统计分布一致 + 端到端一致性实验"，并给出差异归因 |
| 缺 GPU / 训练太慢 | 问题2/3 无法迭代 | 骨干控制在 <5 M 参数；先跑通小配置，用 20% 训练集做快速超参搜索 |
| 附件3 缺失形态与训练模拟不一致 | 性能虚高或虚低 | 先用零值检测统计附件3 的真实缺失分布（率/位置/类型），按实测分布调整模拟引擎参数 |
| 解释被质疑为伪解释 | 问题3 失分 | 三源交叉 + 遮挡型忠实性指标 + 人工复核命中率；不把注意力权重单独当结论 |
| 附件超 50 MB | 违规 | 见第 2 节压缩策略，打包前用脚本核算体积 |
| 混用 aligned/unaligned | 违规 | 配置文件中固定 `FEATURE_VERSION`，数据集类启动时断言版本一致 |

## 6. 快速启动建议（最短路径）

1. `pip install -r code/requirements.txt`（torch、transformers、numpy、pandas、scikit-learn、openpyxl、librosa、matplotlib、scipy、statsmodels）。
2. 先跑 `code/02_model/dataset.py` 的自检：打印 train/valid/test 各字段 shape、标签分布、audio/vision 有效长度极值（验证第 2 节"陷阱 A"）。
3. 用 MMSA 工具箱或自写基线（MulT/MMIM）在附件2 上跑通，得到**全模态基线指标**——这是后面所有对比的锚点。
4. 再按 D1→D4 计划推进。

> 建议把本题的实验配置写成一份 `config.yaml`（特征版本、K、缺失模拟参数、模型超参、损失权重、种子列表），所有脚本从中读取，保证"可复现"这一硬性要求不打折。
