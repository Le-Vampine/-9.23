## 4. 完整实施流程（端到端，命令级）

> 约定：`cd e:\数学建模\code`；CPU 12 线程；单轮耗时实测 教师 ≈99 s、学生 ≈103 s（3395 样本 / batch 64）。

### Stage 0　环境与数据核查（≈5 min）
```powershell
python _env_check.py
python inspect_data.py --version aligned  --save ..\runs\data_report_aligned.json
python inspect_data.py --version unaligned --save ..\runs\data_report_unaligned.json
python inspect_label.py
python check_deliverables.py
```
**产出**：数据核查报告（字段/形状/填充率/真缺失率/标签分布）、交付物清单
**决策点**：确认使用 `aligned`（推荐：体积 1/3、速度 3×、时序已统一）

### Stage 1　A0 基线：复现"性能急剧下降"（≈20 min）
```powershell
python 02_model\train.py --epochs_teacher 1 --epochs_student 1 --seed 42 --out_dir ..\runs\baseline
```
然后用 `runtime.predict_split(..., unaware=True)` 与 `scenario=(...)` 得到"零填充直接推理"的性能 → 作为论文中"常规固定权重融合模型性能急剧下降"的实证（Stage 4 的 `sweep_*_unaware_*` 列即为此基线）。

### Stage 2　超参/结构选择（题目要求，valid 上选；≈2.5–3 h）
```powershell
python 02_model\tune_hyperparams.py --stage screen                 # 8 组 × 子集 768 × 6/8 轮
python 02_model\tune_hyperparams.py --stage full --topk 3          # 前 3 名完整训练 20/30 轮
```
**产出**：`runs/tune/grid_screen.csv`、`grid_full.csv` → 论文"超参数选择"表
**决策点**：取 valid MAE 最小者作为主配置（同时记录 θ）

### Stage 3　主训练（3 种子；≈4–6 h）
```powershell
python 02_model\train.py --epochs_teacher 20 --epochs_student 30 --seed 42 --out_dir ..\runs\q2
python 02_model\train.py --epochs_teacher 20 --epochs_student 30 --seed 43 --out_dir ..\runs\q2
python 02_model\train.py --epochs_teacher 20 --epochs_student 30 --seed 44 --out_dir ..\runs\q2
```
**产出**：`runs/q2/student_s{42,43,44}.pt`（fp16）、`metrics_s*.json`、`history_s*.csv`、`summary.json`（自动汇总 mean±std）

### Stage 4　缺失因素规律分析（题目要求；≈1.5 h）
```powershell
python 02_model\train.py --epochs_teacher 20 --epochs_student 30 --seed 42 --sweep 1 --out_dir ..\runs\q2
python 02_model\analyze_sweep.py --csv ..\runs\q2\sweep_valid_s42.csv --out_dir ..\figs
```
**产出**：`sweep_valid_s42.csv`（6 类型 × 4 位置 × 5 率，含 aware/unaware 对照）、`sweep_test_s42.csv`、退化曲线图、ANOVA 表（Type-III + 偏 η²）、`aware_vs_unaware.csv`

### Stage 5　消融实验（题目要求；≈3–4 h，可用单种子压缩到 1.5 h）
在 `config.py` / 命令行逐项关闭模块后各跑一次（seed 42，20/30 轮）：

| 配置 | 操作 |
|---|---|
| A0 无缺失处理 | Stage 1 的 `unaware=True` 结果 |
| A1 零填充 + 基础融合 | 关闭重建与掩码感知 |
| A2 + 掩码指示 | `ModalityEncoder.forward` 去掉指示位 → 对比 |
| A3 + 重建 | `--lam_rec 0 --lam_rec0 0` vs 默认 |
| A4 + 分解 | `--lam_sim 0 --lam_diff 0` |
| A5 + 代理令牌 | 跳过 β 门控 |
| A6 + 动态专家 | `--n_experts 1` |
| A7 + 蒸馏 | `--no_distill`（**已验证有效：合成数据 MAE 0.41→0.19**） |
| A8 + 不确定性 | `reg_nll` → `mse` |
| A9 完整模型 | 默认配置 |

> 建议把消融开关加进 `config.py`（如 `ablate_mask_indicator`/`ablate_proxy`），使命令统一为 `--ablate xxx`，避免改代码造成不可复现。

### Stage 6　附件3 专项推理（附件到位后；≈1 h）
```powershell
# 6.1 标定测试集缺失分布 → 反推训练模拟参数
python 02_model\calibrate_missing.py --pkl "..\附件3\att3_aligned.pkl" --out_dir ..\runs\q2
# 6.2 若实测分布与训练模拟差异大 → 按建议参数重跑 Stage 3
# 6.3 推理输出
python 02_model\infer_att3.py --pkl "..\附件3\att3_aligned.pkl" ^
  --ckpt_dir ..\runs\q2 --out_csv ..\submission\pred_att3.csv --device cpu
```
**产出**：`pred_att3.csv`（id/pred_label/pred_score/prob_*/confidence/缺失率/缺失区间数）、`pred_att3_full.csv`、`att3_missing_report.json`

### Stage 7　可视化与错误归因（≈20 min）
```powershell
python 02_model\viz_results.py --ckpt_dir ..\runs\q2 --out_dir ..\figs
python 02_model\error_analysis.py --ckpt_dir ..\runs\q2 --out_dir ..\runs\q2
```
**产出**：混淆矩阵、预测-真值散点、误差分布箱线图、缺失掩码可视化、训练曲线、退化曲线、5 维分层归因表、top-20 误差样本表

### Stage 8　论文与附件（≈1 h）
汇总表 → 论文正文（对应 §1 的四项要求）→ 附件打包（特征/代码/权重/说明，≤50 MB，匿名化检查）。

## 5. 本轮新增与修正记录

**新增脚本**：`runtime.py`（共享推理）、`calibrate_missing.py`（缺失分布标定）、`viz_results.py`（论文图）、`error_analysis.py`（分层归因）、`tune_hyperparams.py`（超参搜索）、`check_deliverables.py`、`inspect_label.py`

**修正的问题**（均为实测发现的真实缺陷）：
1. 附件2 无 `*_lengths` 字段 → 改用"尾部全零推断有效长度"，并把 **填充(pad) 与缺失(miss) 严格分离**；
2. `unstack_masks` 同时对 pad 位置置零，避免无效值进入注意力；
3. 新增**时间裁剪增强**（补足首尾缺失场景）；
4. 新增**类平衡交叉熵**（针对 Macro-F1 与 22% 的中性类）；
5. checkpoint 改 **float16**（13.5 MB → ≈6.8 MB，解决附件 50 MB 预算）；
6. `sweep` 增加 **test 代表性场景**（缺失泛化验证）；
7. 修复 matplotlib 中文与样本 id 中 `$` 导致的 mathtext 崩溃；
8. 蒸馏权重与热启动修正（原权重压过任务损失，学生完全不收敛）。

**实测验证结果**：
- 真实数据 1 轮：教师 98.6 s（valid MAE 0.735）／学生 103 s（含蒸馏）
- 分类：test ACC 0.891、Macro-F1 0.883（1 轮欠训练下的初步值）
- 合成数据消融：含蒸馏 valid MAE 0.19 vs 无蒸馏 0.41
- 附件3 推理链路：缺失检测（均值 27%）、集成、CSV、缺失区间输出全部正常
- 图表链路：5 类图 + 4 张归因表 + 缺失标定报告全部生成成功
