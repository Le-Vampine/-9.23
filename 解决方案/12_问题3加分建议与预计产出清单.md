## B. 十条加分建议（按性价比排序）

### B1【最高性价比】把"可解释性模型"做实：并联证据头 + 解释性正则（**预测零改动**）

**为什么**：题目对问题3 的第一条要求是"可解释性模型的建模原理、**网络结构、目标函数、训练方案与关键参数**"。只做事后解释，这一条无内容可写，且创新性会判弱。
**怎么做**：在问题2 骨干上挂一个**并联**的"证据头"（Evidence Head），**不接入预测通路**，因此预测与 `pred_att4.csv` 逐位不变：

- **网络结构**：对三模态共享表示 $H^m\in\mathbb{R}^{K\times d}$，证据头输出时间重要性
  $s^m_k=\mathrm{softmax}_k\big(\mathbf{w}_m^\top\tanh(W_m h^m_k+b_m)\big)$，再以 $\bar h^m=\sum_k s^m_k h^m_k$ 与门控 $\bar g^m$ 汇总为证据向量 $\pi_m$；
- **目标函数**：$\mathcal{L}=\mathcal{L}_{\text{task}}(\text{冻结骨干，仅用于提供表示})+\alpha_1\lVert s\rVert_1+\alpha_2\mathrm{TV}(s)+\alpha_3\sum_m(\pi_m-\pi_m^{occ})^2$；
- **训练方案**：冻结骨干（推理模式、`requires_grad=False`），只训证据头；AdamW、lr $10^{-3}$、30 轮、早停于 valid 的"忠实性−性能"加权目标；
- **关键参数**：$\alpha_1,\alpha_2,\alpha_3$ 在 valid 上网格选择（如各取 $\{0,10^{-3},10^{-2}\}$）；报告选择过程与结果。

**收益**：① 题目要求(1) 有实体可写（结构/目标/训练/参数四件套齐）；② 得到一个真实的可指认创新（"解释忠实性可训练"）；③ 与"事后解释"形成对照实验（§§B3-③）；④ 成本仅 **20–40 min CPU**（只训一个小头）；⑤ **预测不变**，不破坏与问题2 的一致性。
**风险**：几乎无。若验证集上解释指标无改善，如实报告"正则化未带来忠实性提升"，仍是合格结论（诚实是加分项）。

### B2 候选方案对比（评审硬要求，1 页内解决）

在 §5.3 建模开头写"解释方法候选对比"表，**必须差异化（不同模型族）**，并给出选定判据：

| 候选 | 方法族 | 优点 | 缺点 | 判据 |
|---|---|---|---|---|
| C1 注意力权重 | 模型内生 | 零成本 | 注意力≠重要性（有公理化反例） | 作**基线**，不作主口径 |
| C2 代理模型（LIME/SHAP 近似） | 模型无关近似 | 通用 | 需近似采样、结果方差不稳 | 不采用 |
| C3 博弈论精确 Shapley + IG + 遮挡（**选定**） | 公理化 + 梯度 + 模型无关 | 3 模态可**精确枚举**（8 子集），无需近似；三源可互证 | 需多次前向（实测可忽略） | **选它**：满足"可量化、可复核" |

### B3 创新点具象化（3 条，避开伪创新话术）

评审要求"至少 1–2 处明确可指认创新"，且把"给常规方法起新名 / 把现成模块串起来称融合框架"判为**伪创新**。因此本方案的创新点必须落在**结果分析与检验**（评审最容易认可的一类）：

1. **解释的可训练化**（§B1）：把"解释忠实性"写进目标函数，并与事后解释做对照——"新在哪"= 解释头 + 三项正则；"为什么有效"= 用 §B7 的忠实性指标量化。
2. **免标注的机制验证**（§B4）：用**已知缺失**的附件3 与附件4 的整模态缺失样本，验证"缺哪个模态、其 $\pi$ 就低"——解释机制的正确性**不需要任何人工标注**即可检验。
3. **可解释性与鲁棒性的互相印证**（§B6）：$\pi_m$ 的排序必须与问题2"删模态造成的误差增量"的排序一致（文本 ≫ 语音、视觉），一致则两条独立证据链互证；不一致则报告并解释（同样是有效结论）。

> 话术提醒：不要写"本文提出 XXX 融合框架"这类空话；写"本文提出以 xxx 为目标函数的解释头，并用 xxx 实验验证其忠实性提升 x.xx"。

### B4 免标注的机制验证（低成本、高说服力）

- 附件3（30 条，语音 17/30、视觉 18/30 含缺失）与附件4（视觉 1 条整模态缺失）：计算 $\pi_m$ 与**实测缺失率** $\rho_m$ 的关系；
- **预期**：$\mathrm{corr}(\pi_m,\rho_m)<0$ 显著；整模态缺失样本的 $\pi_v\approx 0$（应接近阈值判为 0）；
- 输出：`Q3_模态作用度与缺失率_散点图.png` + Spearman 数值。**无需标注即验证解释正确性**，是本题最"聪明"的一段。

### B5 八子集反事实对照表（Shapley 副产物，兼做消融）

Shapley 计算过程中已得到全部 8 个子集的预测 $\hat y(S)$，可直接整理成一张表：仅文本 / 仅语音 / 仅视觉 / 文+语 / 文+视 / 语+视 / 全模态 / 全缺失（$\varnothing$），配 valid 上的 MAE 与 Macro-F1。它同时是：
- 模态级解释的原始证据（"主要参考模态"有据可依）；
- 消融实验（"单模态能否支撑预测"）；
- 回答"$\varnothing$ 基线为何非零"（模型有偏置项 → 需在论文里说明，避免被当作漏洞）。

### B6 与问题2 缺失实验的一致性检验（全文最亮的呼应）

问题2 已实测：缺失率 1.0 时文本误差增量 **+0.1804**、语音 +0.0002、视觉 +0.0068（文本约为另两者 25 倍）。
问题3 的 $\pi_m$ 若同样指向文本主导，则**两条独立证据链互证**。做法：
- 计算 $\pi_m$ 的样本均值和全局 Shapley（$v=-\mathrm{MAE}$）；
- 与问题2 的模态退化量做 Spearman 相关并画散点图（`Q3_模态作用度与缺失退化一致性_散点图.png`）；
- 结论写成"可解释性结论被鲁棒性实验独立验证"，这是评委最认可的那类"方法学自洽"。

### B7 数值体检与稳健性（避免一致性级扣分）

| 检查项 | 做法 |
|---|---|
| $\pi$ 全负退化 | 双归一化（ReLU 归一 / softmax$\lvert\varphi\rvert$）都报，主口径由 valid 上"与真删模态退化的 Spearman"择优 |
| 屏蔽语义 | `miss=1`（模型语义中的"缺失"）为主，`pad=1`（完全不可见）为对照，报两者 $\varphi$ 的 Spearman |
| IG 基线 | 训练均值（归一化空间=0）为主，"零向量"为对照，比较稳定性指标 |
| 时间映射近似 | 明确声明"附件2 不提供逐词时间戳，段号→秒采用比例映射"；用视频音频能量曲线佐证，不声称精确时间戳 |
| 有效位数 | 全部统计量 3–4 位有效数字；百分比保留 1 位小数 |
| 人工判读 | 抽 30 条 valid，人工判读高亮片段是否含情感线索，报**命中率**（题目要求"可复核"，这是最直接的证据） |
| 边界情形 | 报告 $r$（top-$r$ 片段）取 3/5/10 时忠实性指标的变化趋势，防"结论只对某个 $r$ 成立" |
