## 一、三个口径陷阱（务必先读，否则对比表会做错）

### 陷阱 1：文献报的是 Acc-2，我们主报的是三分类 ACC

CMU-MOSEI 系文献（MulT、MISA、MMSA 等）几乎一律主报 **二分类 Acc-2 与 F1**，
即把情感判成"负面 / 非负面"两类的准确率；而题目要求的是**三分类**（负/中/正）的 Accuracy 与 F1。

**这两组数字不能放在同一列比较。** 直接把我们的三分类 ACC 0.6223 写进"文献 ACC 列"是错的；
我们的 Acc-2 是 **0.8514**，这个才是能和文献对齐的数。

### 陷阱 2：Acc-2 有三种实现路径，数值差 0.02 至 0.07

同一模型不同实现方式得到的 Acc-2 差别很大。本文固化采用**分类头概率构造**口径（即
$p_{\text{neg}}$ 对 $p_{\text{neu}}+p_{\text{pos}}$），理由与对照数值见
`05_方案文档/07_问题2指标口径与合规性说明.md` 第 3.1 节。

**引用文献数字时必须同时说明对方的 Acc-2 实现口径**（是否排除中性样本），否则不可比。

### 陷阱 3：我们的训练集只有 3395 条，公开设定是 16326 条

赛题附件二提供 4850 条样本，划分 3395 / 728 / 727；CMU-MOSEI 官方划分是
16326 / 1871 / 4659，**训练规模相差约 4.8 倍**。

因此**不能**写"本文优于/劣于某某方法"，只能写"在约五分之一的训练规模下达到公开结果的量级"。
这句话本身就是加分点——小数据下取得可比指标，说明特征与融合设计有效。

> 所需写法示例：
> "本文仅使用赛题提供的 3395 条训练样本，约为公开设定的四分之一，故与公开结果不作严格优劣比较，仅作量级参照。"

## 六、填对比表时的红线

1. **不得编造文献数值。** 每一格都必须能指回原文的具体表格或段落。本模板刻意把数字列留空。
2. **不得跨口径比较。** 三分类 ACC 与 Acc-2 不同；验证集与测试集不同；全模态与缺模态不同。
3. **不得省略训练样本数**。我们的 3395 与公开的 16326 必须写明，否则构成不公平比较。
4. **不得把这套数字说成"刷新"或"领先"**，除非真的在同一设定、同一划分、同一口径下复现了对方。

## 七、相关工作段落的结构建议（可直接照此组织）

1. **多模态情感分析基线**：介绍 MulT\cite{ref2} 一类的跨模态注意力方法与其在全模态干净设定下的表现。
2. **缺模态鲁棒性**：介绍赛题[2][3][4][7] 一类的补全/蒸馏/动态专家思路，指出它们多数假设整模态缺失。
3. **本文的差异**：本文处理的是**局部连续时段**缺失（题目定义），要点是"缺失位置与时长的显式建模"，
   并以连续零值掩码参与注意力与池化；这一点与整模态缺失设定不同。
4. **对比结论**：在约五分之一训练规模下，本文 Acc-2 达到 0.8514，落在公开干净设定区间的下沿；
   在缺失鲁棒性维度上，本文以自建的两个朴素融合基线为对照，退化降低 1.5 至 3.3 倍。
