## 7. 结论

1. 主报口径（valid，θ 阈值）：MAE=0.5873、Pearson=0.6610，ACC=0.6195、Macro-F1=0.6082。
2. 泛化核验（附件2 test 划分）：MAE=0.6521、ACC=0.6149、Macro-F1=0.5918；两划分的落差中约 0.028 由标签强度分布差异解释。
3. 校准（系数在 valid 上拟合，推荐方法 `ols`）：回归指标两划分均改善（valid MAE 0.5873→0.5826；test MAE 0.6521→0.6485），分类指标在 test 上明显改善（ACC 0.6149→0.6341；Macro-F1 0.5918→0.6091），但在 valid 上略降（ACC 0.6195→0.6113）。按赛题“模型结构、超参数与决策阈值在验证集上选择”的规则，**主口径保持不校准**，校准列为可选改进与敏感性分析。
4. 双头融合在 valid 上最优 α=0.0，说明回归头已包含分类头信息，融合无增益。
5. 非对称阈值在 valid 上最优退化为对称（θ_neg=θ_pos=0.30），无需引入与题目“0 仅属中性”定义不一致的改动。
6. 论文需说明：θ、校准与融合系数均在验证集上拟合，附件3/4 未参与任何选择；若最终采用校准方案，附件3/4 的提交 CSV 必须由同一后处理生成（`infer_att3.py --calib_a a --calib_b b --theta θ`）。
