## 7. 结论

1. 主报口径（valid，分类头 argmax）：ACC=0.6250、Macro-F1=0.6205；配套强度指标 MAE=0.5862、Pearson=0.6547。
2. 泛化核验（附件2 test 划分，分类头 argmax）：ACC=0.6465、Macro-F1=0.6280、MAE=0.6272；两划分的 MAE 落差中约 0.007 由标签强度分布差异解释。
3. 口径差异：两口径一致率 valid 0.819 / test 0.839。θ 口径需在 valid 上选阈值且对强度分数尺度敏感（强正则/校准会移动 θ），分类头无此问题——故论文必须显式声明主口径。
4. 校准（只作用于 θ 分支，系数在 valid 上拟合，推荐方法 `ols`）：θ 分支 MAE 0.5862→0.5800（valid）、0.6272→0.6277（test）；主口径（分类头 argmax）不经过校准，不受其影响。
5. 双头融合在 valid 上最优 α=0.0（说明回归头已含分类头信息，无增益）；非对称阈值在 valid 上最优退化为对称（θ_neg=θ_pos=0.15），故不引入与题目中性定义不一致的改动。
6. 论文需说明：θ、校准与融合系数均在验证集上拟合，附件3/4 未参与任何选择；提交 CSV 的 `pred_label` 采用主口径，另一口径以并列列（`pred_label_theta` / `pred_label_head`）写出。
