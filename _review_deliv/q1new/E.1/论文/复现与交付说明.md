# 问题一复现与交付说明

## 结果范围

附件候选包包含 100 条样本的逐样本词级三模态矩阵、原始时序特征、逐词时间和对应索引、全量质量检查结果、代码与配置。原始 100 条 MP4、从中分离的 WAV、BERT/Whisper/MediaPipe/MFA 模型权重不打包；这些文件远超赛题 50 MB 附件上限，需由附件 1 和说明中列出的模型来源重建。候选包不等于问题二、三的最终提交包。

## 读取主结果

`结果/08_原文词级跨模态对齐/逐样本/<sample_id>.npz` 是主特征文件。每个文件按题目 `text` 的原文词序保存，`valid_length` 等于原文词数；本步骤未把序列补到固定长度。文本、音频、视觉矩阵形状依次为 `(valid_length,768)`、`(valid_length,74)`、`(valid_length,52)`，类型为 `float32`。每一行都对应 `结果/08_原文词级跨模态对齐/逐词对齐索引.csv` 的同一样本编号和原文词序。

读取时必须同时读取 `word_time_valid_mask`、`audio_valid_mask`、`visual_valid_mask` 和 `audio_f0_valid_mask` 等有效性信息；无时间词的时间为 NaN，缺失音视频特征为零占位。补齐到批处理长度时，应在下游新建 padding mask；不得将零占位解释为真实观测。具体键名与单位以 `结果/08_原文词级跨模态对齐/对齐规则.json` 及逐词索引表为准。

```python
from pathlib import Path
import numpy as np

sample_id = "-vxjVxOeScU$_$4"
base = Path("E.1/结果/08_原文词级跨模态对齐/逐样本")
with np.load(base / f"{sample_id}.npz", allow_pickle=False) as item:
    text = item["text"]
    audio = item["audio"]
    visual = item["visual"]
    valid_length = int(item["valid_length"])
    time_mask = item["word_time_valid_mask"].astype(bool)
    audio_mask = item["audio_valid_mask"].astype(bool)
    visual_mask = item["visual_valid_mask"].astype(bool)
```

## 复现顺序与版本

按 `E.1/README.md` 记录的命令顺序执行步骤 1 至 10。步骤 3 使用 faster-whisper 1.2.1/CTranslate2 4.8.2 的 `small.en`，CPU int8、beam size 5、词级时间戳开启；步骤 4 使用 MFA 3.4.2、`english_us_arpa` 词典与声学模型；步骤 5 使用固定修订版 `google-bert/bert-base-uncased`，不微调；步骤 6 使用 librosa 0.11.0、16 kHz、2,048 点窗、160 点帧移；步骤 7 使用 MediaPipe 0.10.32、Face Landmarker VIDEO 模式和约 10 fps 原帧 PTS；步骤 10 使用 `.vision_env` 执行 `代码/质量检查/生成第10步论文证据.py`。

模型固定信息和哈希在 `配置/第一问流程配置.json`。模型公开来源：

- BERT：`https://huggingface.co/google-bert/bert-base-uncased`
- Whisper small.en 的 faster-whisper 转换版：`https://huggingface.co/Systran/faster-whisper-small.en`
- MFA：`https://montreal-forced-aligner.readthedocs.io/`
- MediaPipe Face Landmarker：`https://ai.google.dev/edge/mediapipe/solutions/vision/face_landmarker`

重跑需要将原始附件 1 的 `label-100.xlsx` 与 100 条 MP4 放入 `E.1/输入/` 中规定的目录，并根据本机安装位置调整 FFmpeg 与各 Python 环境命令。Step 1 脚本曾用于核验原始附件与 E.1 副本的 SHA-256；由于该步骤涉及解压源目录，迁移到另一台机器时需先更新其源路径。候选包的主结果可直接读取，不依赖模型权重。

## 质量与限制

第 10 步对 100 个主 NPZ 执行行数、维度、样本编号、词数、时间顺序、掩码与逐词索引的一致性检查，结果见 `结果/10_全量质量检查与论文图表/全量核验与论文数据.json`。100 个样本全部有主文件；1,934 个原文词全部有文本向量；1,421 个词有自动筛查后的主时间和音频；1,228 个词有词区间内的有效视觉。513 个词的主时间为空。由于缺乏人工词边界，不能推断其绝对时间误差。
